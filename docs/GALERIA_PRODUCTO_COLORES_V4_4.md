# ROY Enterprise 4.4 - Galería principal e imágenes por color

## Comportamiento corregido

1. Al abrir **Ver opciones**, la ficha carga primero la imagen principal y todas las imágenes adicionales del catálogo.
2. Ningún color se selecciona automáticamente.
3. Cuando el cliente selecciona un color, la galería cambia únicamente a las imágenes registradas para ese color.
4. Si un color no tiene imágenes propias, se conserva la galería principal.
5. Para añadir el producto al carrito, el cliente debe seleccionar un color cuando el producto tiene colores configurados.
6. Las miniaturas de la tarjeta del catálogo usan la imagen principal y las adicionales, no las variantes de color.

No requiere cambios en las reglas ni en las colecciones de Firebase.
