# ROY Enterprise 4.0 - Menú y categorías

## Qué se agregó
- Constructor de menú desde el panel administrativo.
- Crear, editar, ocultar, eliminar y ordenar opciones.
- Vincular opciones con páginas, categorías o enlaces externos.
- Agregar automáticamente categorías existentes al menú.
- Portada, descripción, icono y resaltado por categoría.
- Menú sincronizado en computadora y celular.

## Firebase
La configuración se guarda en `roy_settings/main`, dentro del campo `navigation`. Las reglas actuales ya permiten esta operación para usuarios autorizados. No se necesita crear una colección nueva.

## Uso
1. Inicia sesión en el panel.
2. Abre **Menú web**.
3. Pulsa **Agregar opción** o **Agregar categorías faltantes**.
4. Ordena con las flechas.
5. Guarda. Los cambios aparecen inmediatamente en la tienda.

Los productos se asignan a una categoría desde Catálogo > Productos > Crear/Editar producto.
