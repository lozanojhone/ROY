# ROY Enterprise 5.1 - Ficha de producto responsive

- Diseño de ficha adaptado al ejemplo entregado: galería grande en PC y composición compacta en celular.
- Se conserva el proceso formal de compra: selección de variante, añadir al carrito, checkout, pago y registro del pedido.
- La imagen ligera del propio producto se usa como primera carga; se eliminaron los reemplazos visuales con el logotipo ROY.
- Las fotografías usan `object-fit: contain` para evitar recortes y deformaciones.
- En celular, el botón Añadir al carrito permanece visible en la parte inferior.
