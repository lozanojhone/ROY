# ROY Enterprise 4.8 - Imágenes principales instantáneas

- La miniatura principal se guarda dentro del documento `roy_products`.
- La tarjeta no necesita consultar `roy_product_images` para mostrar su primera foto.
- Los productos antiguos se migran automáticamente cuando entra un administrador autorizado.
- Las primeras tarjetas usan prioridad alta y carga inmediata en PC y móvil.
- No se muestra el texto “Cargando”.

## Paso importante
Después de publicar la versión, entra una vez al panel administrativo y espera a que aparezca el catálogo. Esa entrada migra los productos antiguos. Desde entonces, todos los navegadores reciben la miniatura junto con el producto.
