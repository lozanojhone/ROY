# ROY Luxury 5.2

- Los colores configurados desde el panel ahora controlan toda la interfaz.
- Negro, blanco y dorado son valores predeterminados, no bloqueos rígidos.
- Se eliminaron los productos demostrativos del arranque.
- Firestore `roy_products` es la fuente oficial del catálogo.
- Una colección vacía muestra una tienda vacía.
- Productos y configuración se actualizan en tiempo real con `onSnapshot`.
- El Service Worker usa red primero para HTML, CSS y JavaScript.
