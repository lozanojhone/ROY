# ROY Enterprise 5.3 - Galería estable

- La ficha siempre abre en **Generales**.
- En móvil, las miniaturas permanecen al costado izquierdo.
- Cada color carga sus propias fotografías y **Generales** restaura las principales.
- La fotografía visible no se elimina mientras llega la siguiente.
- La imagen original sustituye a la versión ligera únicamente después de terminar de cargar.
- Todas las fotografías usan el mismo marco, centrado y `object-fit: contain`, sin deformación ni recorte.
- Se precargan las fotografías disponibles y las originales de los colores.
- No se modificó el flujo de carrito, checkout, pagos, inventario ni administración.
